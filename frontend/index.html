    About this project

    This is my graduation project for Manara AWS 2: Becoming a Solutions Architect. It's a simple to-do list that runs on AWS and its serverless.

    You can try it as a guest and your tasks will stay in your browser. If you create an account, your tasks are saved in the cloud and you can see them from any device.

    Built with Amazon Cognito for login, API Gateway and Lambda for the backend, DynamoDB for storing tasks, and S3 with CloudFront for hosting this page.
